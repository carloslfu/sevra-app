total: Send to the reply drawn. text: first answer text on screen. shown: saved reply in the
chat. pre: Send to the first engine request. start: engine start. prep: prompt building
and tokenizing. gram: grammar compile. engine: engine request time, of which prefill and
decode as the engine counts them, and mask the host spent on grammar masks. prompt and
match: tokens of the first call and how many it resumed. comp: tokens computed in all calls.
gen and think: tokens generated and of those, hidden reasoning. tool: tool time. maint: context
maintenance. lock: waits for the workbook lock. late: main thread lateness over 20 ms.
