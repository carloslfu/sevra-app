# Chat history panel request

On November 21, 2026 the owner asked what the best way to see chat history is, whether
a panel should slide in rather than a menu, and whether the dropdown menu of chat titles
was right. He asked for a first-principles UX analysis.

The analysis recommended a chat list shown in place of the open chat in the chat pane:
search, chats grouped by last activity with their times, the open chat marked, Rename
and Delete on each row, full keyboard use. A permanent sidebar was rejected because the
chat is already a side pane; a popover was judged too cramped for a long list.

The owner replied: "Build it".
