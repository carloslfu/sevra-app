# Cut context for ordinary workbook requests

Carlos then directed: "Why only greetings? I want to cut context for normal workbook requests too. Update the plan with the simplest router that gives those requests only the tools they need."

He added: "Think about this thoroughly and use your best taste Is this really the way to do this? Do also deep research on the best ways to do this for agents, and if we really need it, instead of a deterministic router, we might need an LLM router. Use your best case. Reason from first principles."

This asks for a plan revision and supporting research. It does not ask for implementation, a model download, app installation or UI testing.
