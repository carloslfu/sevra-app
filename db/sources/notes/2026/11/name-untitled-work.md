# Owner asks for untitled workbooks and chats to be named smartly

On November 22, 2026, Carlos asked: "The titles. Don't you think the titles should be smartly updated when they're untitled? What is the best UX for this?"

The agent proposed that the local model name a workbook and its chat in the background after a reply, keep improving a name it gave while the work takes shape, never change a name the person gave, show the new name at once and move the file when nothing holds it. He answered "do it".

## The agent's reading

- **Stand-in names get real ones:** "Untitled", "New chat", a chat titled with its first message and a workbook named from a message's first words.
- **The model names them after a reply,** in the background on the engine the reply left running, and any new request stops it first.
- **A greeting gets no name** until there is work to name.
- **A name Sevra gave may improve during the first three replies,** then stays.
- **The person's name is final.** Renaming stops Sevra for that workbook or chat.
- **The name shows at once** in the window, header, chat and recent lists. The workbook's file takes the name the next time it opens, since nothing may hold it while it moves.
