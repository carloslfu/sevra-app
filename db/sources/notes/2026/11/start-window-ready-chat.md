# Owner asks for the start window to be a chat that is ready to use

On November 22, 2026, Carlos sent a picture of the start window, with its four ways to begin and its list of recent workbooks, and wrote:

"The initial page, shouldn't it be a chat, ready to use, instead of forcing the user to choose something? [...] that whole window could be avoided, don't you think so? Maybe there is always a new workbook there, or what? [...] Maybe there is a default folder for workbooks, and people don't worry about where to put what, which is friction. We want to remove friction. Maybe there is a default, like when people start working, it saves it by default. [...] These patterns that reduce the friction and make people actually start using stuff, and maybe making the workbook easy to rename, stuff like that."

He asked for the options to be reasoned from first principles. After the analysis he wrote: "Okay, think deeply about how to improve this and make it happen."

## The agent's reading

- **The start window is ready to type into.** It holds a message field, an Add files button and a drop target. It asks for no choice before the work starts.
- **The first message or the first files make the workbook.** Nothing is written before that, so an unused start window leaves no empty workbook behind.
- **New workbooks go to a default folder with no save panel,** named after their first files or the start of their first message. The example workbook and an opened portable workbook go there too.
- **A workbook is renamed from its own name in the header,** and its file is renamed with it.
- **Recent workbooks stay one step away:** on the start window, in the workbook's name menu and in File > Open Recent.
- **Choosing a place is still possible,** from File > New Workbook in Folder.
