# Owner asks for a button and a size setting for views

On November 23, 2026, with the defaults work installed, Carlos asked "What are we missing?" The agent listed what was left and named the largest gap against his first request, "Change my Home to show a big counter button": a view had no button and no size setting, so the request gave a number of ordinary size that showed 0 and that nothing on Home could change. The agent said the feature "needs one product choice from you: what pressing the button does, such as adding a row to the counted table", and asked: "Should I build a button and a size setting for views next?"

He answered: "Yes, build it".

## The agent's reading

- **He did not choose what a press does.** By his own rule from earlier the same day, a choice gets a default. The agent took the example it had given him: a press adds one empty row to the button's table, so a count of that table goes up by one.
- **A size is a small set, not a number.** Small, medium and large, on a counter and on a button.
- **A press can be taken back,** because an accidental press on a counter should cost one click to fix.
