# Contextual import and Excel continuity, October 28, 2026

Owner-confirmed direction relayed from Carlos's authorized side conversation to
the active implementation chat. This is a record of the received direction,
not a verbatim transcript of the other conversation or evidence of delivery.

Import must be first-class both when starting a workbook and during ongoing work.
An empty workbook/home needs a prominent calm way to start from existing files;
an existing workbook needs a persistent discoverable way to add files or data.
Both enter the same capability. Voice/text remain central, complemented by native
controls, file drag/drop and appropriate paste, including spreadsheet ranges.
Illustrative labels Start from a file and Add files or data are not approved final
copy. Import cannot be hidden in chat or restricted to onboarding.

File format does not determine role. CSV or Excel may become native working
tables, reference data, analysis inputs, or updates/merges to existing tables.
Infer intent from the request and workbook context; ask briefly when a consequential
choice is materially ambiguous. Never silently append, replace or merge. Any
supported input can start a workbook. Excel merits richer conversion because it
contains structure and behavior, not because it is a required starting format.

Excel continuity includes supported sheets, rows/columns, tables, headers, formulas,
dependencies, named ranges, useful formatting and relevant workbook functionality.
Preserve originals and lineage. Disclose unsupported/lossy features and separate
cached values from working recalculations. Extracting values does not establish
functional migration or complete compatibility. Scope legacy/complex features.

Inspect current code, reconcile the design and progress registry, and carry the
direction into implementation and acceptance for startup/ongoing CSV and Excel,
contextual roles, ambiguous intent, structure/formulas and truthful completion.
Preserve in-flight work, use focused verification and change only this repository.
